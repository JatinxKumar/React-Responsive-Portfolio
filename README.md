# 🚀 Jatin Kumar's Portfolio

A modern, responsive developer portfolio built with **Next.js**, **React**, and **Tailwind CSS**.

This portfolio showcases my skills, professional experience, featured projects, education, resume, and contact information through a clean and interactive user interface.


## 🌐 Live Demo

Website: [jatin-dev.vercel.app](jatin-dev.vercel.app)

## 🚀 Running Locally

### Clone the Repository

```bash
git clone https://github.com/JatinxKumar/React-Responsive-Portfolio.git
```

### Navigate to the Project Directory

```bash
cd React-Responsive-Portfolio
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

### Visit the Application

Open your browser and visit:

```text
http://localhost:3000
```
